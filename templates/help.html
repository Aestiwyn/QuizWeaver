了解 TeachFlow 中的语言模型

您无需成为技术专家，也能负责任地使用语言模型。本节说明 TeachFlow 如何使用语言模型、它们能做和不能做什么，以及您如何始终保持控制。

生成式语言模型（通常称为 LLM，即大型语言模型）是一类根据从大量既有文本中学习到的模式生成新文本的软件。TeachFlow 生成测验时，会将课程相关信息发送给语言模型，再由模型产出题目草稿。

可以这样理解：输入课程内容，语言模型进行处理，输出题目草稿。模型并不会像教师一样“理解”课程，而是根据已见模式预测合适的测验题目可能是什么样子。

LLM 生成的内容是草稿，不是可直接交付的成品。语言模型可能生成看似自信却不准确、不完整或带有偏差的内容，这种情况有时称为“幻觉”。

  • 准确性 — 模型可能包含错误或不够精确的事实，您最了解所教内容。
  • 偏差 — 语言模型会反映训练数据中的模式，其中可能存在文化或人群偏差。
  • 适切性 — 只有您最清楚什么内容适合特定学生和课堂情境。

TeachFlow 支持您在题目给到学生之前编辑、重新生成或舍弃任何 LLM 生成的题目。

TeachFlow 强调透明，而不是“黑箱”。您始终可以查看：

  • 使用了哪项内容来源 — 为该测验选择的课程记录或输入内容
  • 目标课程标准 — 测验详情页显示的 SOL 对齐信息
  • 语言模型接到的任务 — 每份测验均显示题目数量、难度和年级等生成参数

这些信息有助于您判断生成结果是否符合教学目标。

TeachFlow 中并非所有内容都由 LLM 生成。重要的教学约束由规则而不是语言模型执行：

  • 评分标准的评价维度 — 起步、发展中、熟练、进阶等水平遵循固定结构
  • 题型分布 — 单项选择、简答等题型组合遵循您的设置
  • 课程标准对齐 — SOL 课程标准根据您的输入匹配，而非由语言模型解读

这意味着语言模型在您设定的边界内工作：它生成内容，但结构来自成熟的教学框架。

TeachFlow 按默认保护隐私的原则设计：

  • 数据库存储在本地 — 所有班级、课程、测验和学习表现数据均保存在计算机（或服务器）的 SQLite 数据库中，不会发送到云端数据库。
  • 发送给语言模型的内容 — 使用真实模型服务生成测验时，TeachFlow 会发送课程摘要和主题列表，但不会包含学生姓名、成绩或个人身份信息（PII）。
  • Mock 模式不会发送数据 — 使用默认 Mock 模型服务时，数据不会离开您的计算机，完全离线。

是否连接真实 LLM 模型服务始终由您决定。TeachFlow 默认以 Mock 模式运行，不会进行外部数据共享。

LLM 模型服务按Token（文本的小单位，通常每个词约一个 Token）计费。TeachFlow 向语言模型发送课程内容并接收题目时，输入和输出都会以 Token 计量。

  • Mock 模式免费 — 默认模型服务免费生成占位内容，可先探索 TeachFlow，再连接真实模型服务。
  • 真实模型服务会产生费用 — Google Gemini、OpenAI 等服务按 Token 计费，TeachFlow 会在成本页面跟踪费用。
  • 每次真实调用均由您确认 — 生成前会显示成本估算，您可以随时取消。

使用多数模型服务生成一份典型的 20 题测验，费用通常仅为几美分。成本页面会显示累计费用。

流程概览

TeachFlow 通过以下三个步骤生成贴合实际教学内容的测验：

  1. 新建班级 - 为每个班级或课时设置年级和课程标准。 现在新建班级
  2. 记录课程 - 记录每天的授课内容，系统会从内容中自动识别主题。
  3. 生成测验 - TeachFlow 使用课程记录生成符合学生实际所学的测验。

班级管理

新建班级
前往班级 > 新建班级。填写班级名称（必填），也可填写年级、学科和 SOL 课程标准。
编辑班级
在班级详情页点击“编辑班级”，即可更新名称、年级、学科或课程标准。
删除班级
在班级详情页点击“删除班级”。此操作会删除班级及其全部课程记录，但已生成的测验会保留。
查看班级详情
点击班级名称可查看已掌握知识（至今已授主题）、课程记录和已生成测验。

记录课程

文字录入
描述授课内容，包括核心概念、活动和覆盖主题。内容越具体，生成的测验越贴合。
上传文件
您可以上传包含课程材料的 PDF 或 DOCX 文件，而不必手动输入内容。
自动识别主题
主题字段留空时，TeachFlow 会从课程内容中提取主题；也可用逗号分隔手动输入。
已掌握知识
随着课程记录增加，TeachFlow 会汇总学生应掌握的内容，并在班级详情页展示，供生成测验时使用。

生成测验

题目数量
选择要生成的题数（1–50），默认值为 20。
年级
默认从班级设置带入，用于调整题目难度和词汇水平。
SOL 课程标准
测验会使用班级中已保存的课程标准；课程标准代码例如 SOL 7.1。
Mock 与真实模型服务
TeachFlow 默认使用Mock 模式，这是返回预设占位内容的演示／测试模式。Mock 生成的测验不会根据课程定制，而是使用通用示例题，便于您零成本了解界面。如需生成真实、贴合课程的测验，请在设置中配置真实 LLM 模型服务。
测验状态
已生成 = 可供教师确认， 生成中 = 正在生成， 失败 = 生成时出现错误。

模型服务设置

要生成依据课程定制的测验，请连接真实 LLM 模型服务。TeachFlow 支持以下选项：

Google Gemini
从 Google AI Studio 获取免费 API 密钥。在设置中填写密钥并选择 Gemini 模型服务。
OpenAI
从 platform.openai.com 获取 API 密钥。在设置中填写密钥并选择 OpenAI 模型服务。
本地模型（Ollama）
可使用 Ollama 或任何 OpenAI 兼容服务器运行本地模型。在设置中选择“OpenAI 兼容”，并设置基础 URL，例如 http://localhost:11434/v1。
测试连接
填写模型服务信息后，在设置页面使用“测试连接”按钮，确认连接正常后再保存。

成本跟踪

显示内容
成本页面显示 API 用量、总费用和当前 LLM 模型服务。
Mock 模型服务 = 演示模式
使用默认 Mock 模式时，所有测验生成均完全免费，也不会发起 API 调用。但内容是通用占位文本，不会根据课程定制。
真实模型服务的费用
使用 Gemini 或 Vertex AI 时，系统会按请求跟踪费用并在成本页面显示。每次真实 API 调用前都会请求您的确认。

提示与故障排除

测验生成失败
请确认班级至少已有一条课程记录。测验生成器需要课程内容作为依据。
未识别到主题
请在主题字段中用逗号分隔手动输入。自动识别对详细、描述性强的课程内容效果最佳。
获得更好结果
请定期记录详实课程内容。TeachFlow 掌握的课程背景越充分，题目越能贴合学生实际所学。
多个班级
每个班级独立跟踪课程和知识，测验也按班级生成，因此不同课时的学生会获得符合各自教学内容的测验。
