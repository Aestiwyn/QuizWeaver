# 教师助手 Demo 后续事项

记录日期：2026-09-06。当前分支：teacher-copilot。

本文件用于跟踪教师助手 Demo 的后续事项。已完成项目按实际实现和验证结果更新；未明确处理的事项继续保持待办。

## 本轮确认的行为与待讨论方案

- [x] DEMO-01：首页“生成测验”和“记录课程”不再使用 `classes[0].id`。两个入口先进入只允许 `generate-quiz`、`log-lesson` 两种目标的班级选择流程，再进入 URL 锁定的生成或记录页面；班级详情中的按钮仍直接使用当前班级。表单不提供班级切换控件，后端按 URL 中的 `class_id` 校验和保存。
- [x] DEMO-02：`Legacy Class (Pre-Platform Expansion)` 保留为兼容旧数据的默认班级，迁移逻辑、原始名称、已有测验和归属均未修改。所有页面通过展示层过滤器将其显示为 `Default Class (Legacy Data)`；其他班级名称原样显示。
- [x] DEMO-03：项目继续使用现有英文界面，不新增国际化框架。相关英文原文明确使用 `Class`、`Choose a Class`、`Log Lesson` 和 `Lesson Logging`，语义分别对应“班级”“选择班级”“记录课程”“课程记录”；浏览器自动翻译的具体措辞不由项目控制。

## 上轮代码检查发现的问题（暂缓修复）

- [ ] DEMO-04：课程表单有 `lesson_date`，保存接口未读取或传入所选日期，记录默认使用当天。位置：`templates/lessons/new.html`、`src/web/blueprints/classes.py::lesson_log`。
- [ ] DEMO-05：课程表单有 PDF/DOCX 文件上传字段 `lesson_file`，保存接口没有处理文件。建议 V1 先隐藏未接通的上传，只支持文本；是否实现解析另行决定。
- [ ] DEMO-06：课程正文虽有前端 required，但保存接口未拒绝空白正文；需要服务端校验。
- [ ] DEMO-07：生成流程自动加载当前班级最近 14 天课程记录。建议明确展示并选择本次使用的课程，避免用户不清楚生成依据。位置：`src/agents.py::run_agentic_pipeline`。
- [ ] DEMO-08：生成进度按定时动画推进，不是后台实际阶段反馈。建议先使用真实的等待、成功、失败状态，避免用动画表示已完成审核。位置：`templates/quizzes/generate.html`。
- [ ] DEMO-09：详情页将 `metrics.approved` 为 false 的情况统一标为达到重试上限，无法准确表达 Critic 异常等原因。位置：`templates/quizzes/detail.html`、`src/agents.py`。
- [ ] DEMO-10：已有题目编辑和审核提醒，但本次检查未找到独立的教师确认接口/状态。建议区分 AI 检查与教师确认，编辑后标记已有审核结果过期；属于拟新增能力。
