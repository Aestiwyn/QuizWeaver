# TeachFlow five-minute demo script

Use the isolated, Mock-provider setup in [DEMO.md](DEMO.md). All names, lesson
content, and files below are fictional.

**0:00–0:40 — Select a class.** Create or select **七年级科学 A 班**. Explain that
classes isolate lessons and quizzes.

**0:40–1:30 — Add source material.** Record a lesson named “植物如何获得能量”,
upload a fictional text-based document or enter the sample content manually.
Point out that a lesson must have text or an extractable PDF/DOCX.

**1:30–2:20 — Generate with Mock.** Choose that lesson in **生成测验**, select
five questions, and retain Mock. Explain that no real API or student work is
sent anywhere.

**2:20–3:10 — Inspect the source.** Open the generated quiz, expand
**本测验的生成依据**, and show the selected source, the Critic result, and cost.

**3:10–4:10 — Teacher review.** Edit a question, explain that this requires a
fresh review, then click **确认测验可用** only after checking accuracy and fit.

**4:10–5:00 — Export.** Export a teacher version and a student version; show
that the student version does not expose answers.
